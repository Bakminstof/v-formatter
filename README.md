# V-Formatter

Простой GUI-инструмент для работы с видеофайлами.

В качестве бэкэнда используется [**FFmpeg**](https://www.ffmpeg.org/)

## Возможности
- Склейка видеофайлов (конкатенация) без перекодирования.
- Графический интерфейс на `PyQt`.

## Установка и запуск
```bash
git clone https://github.com/Bakminstof/v-formatter.git
cd v-formatter
Run.cmd
```
